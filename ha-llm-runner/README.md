# HA LLM Runner

Run LLM tasks over your Home Assistant data and get the results as sensors.

- Analyse sensor history (e.g. the last 48 hours) with an LLM
- Describe camera snapshots, e.g. who is ringing the doorbell
- Attach files, calendars and web pages to your prompts
- Structured JSON answers become sensor attributes
- Results are published via MQTT discovery and survive restarts

See the **Documentation** tab for setup and examples.
